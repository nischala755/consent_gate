HOW IT WORKS

A trusted task, then a checked read

  1. IssueThe application creates a short-lived, signed task for one order.
  2. CheckThe gateway verifies consent, resource ownership, operation, and policy version.
  3. MinimizeThe controlled connector selects only the permitted fields.
  4. RecordA metadata-only decision record makes the result explainable.
